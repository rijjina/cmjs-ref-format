# CMJS Reference Format Rules

**General rules:**
- Font: Calibri 10pt
- Numbered: [1], [2], etc. with tab after number
- Author names: `Surname Initial.` (e.g., `Pathom-aree W.`)
- If >6 authors: list first 6, then `et al.`
- Title: sentence case
- DOI format: `DOI 10.xxxx/xxxx`
- In-text citation: [1], [2-4], [1,3,5]

**Per-type formats with examples from template:**

| Type | Format |
|------|--------|
| Journal | `[n] Surname I., Surname I. and Surname I., Title sentence case. *Journal Name*, Year; **Vol**(issue): Pages. DOI xxx.` |
| Book (Texts) | `[n] Surname I. and Surname I., *Title*, Edition, Publisher, City, Year.` |
| Book Chapter | `[n] Surname I., Chapter title; in Editor I. and Editor I., eds., *Book Title*, Publisher, City, Year: Pages.` |
| Thesis | `[n] Surname I., *Title*, PhD/MSc Thesis, University, Country, Year.` |
| Patent | `[n] Surname I., *Country Pat. No.* XXXXX (Year).` |
| Proceedings | `[n] Surname I., Title, *Proceedings Name*, Location, Date; Pages.` |
| Online | `[n] Surname I., Title; Available at: URL. (Accessed on Date).` |
| Report | `[n] Surname I., Title (Report No. XXX). Organization. Year. Available at: URL` |
| Article in press | `[n] Surname I., Title. *Journal*, DOI xxx.` |

**Formatting details:**
- Journal names: italic (full name, not abbreviated unless already standard)
- Volume: bold
- Book/thesis titles: italic
- Proceedings names: italic
- Patent country name: italic
- Separator between authors: comma, last author uses 'and'
